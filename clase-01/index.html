Conectar todo, sin escribir código.

En acción con n8n

Para automatizar agrupamos herramientas. Veamos un ejemplo real: Recibís un email gigante de un cliente y querés leer solo lo importante al instante.

1. Trigger: El Webhook

Un Webhook es una "puerta abierta" esperando datos. Llega ese correo eterno, y Gmail empuja la alerta directamente a esa puerta en n8n.

2. API & Procesamiento IA

Una API es un mensajero universal. n8n usa la API de Gemini enviándole el correo con una instrucción muy clara: "Extrae los 3 puntos clave de este texto".

3. Resultado

Gemini lee y devuelve el resumen. n8n utiliza otra vez la API de Gmail para auto-enviarte un correo limpio, destacando exclusivamente esos 3 puntos vitales.
